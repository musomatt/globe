# Archived active-user visualisations

The simulated-data layer was removed from the application on 9 November 2026. These source files and their fixture are retained as an archive of the earlier column and halo experiments, following the request to keep the visualisation code.

Nothing here is imported by the application or included in its production bundle. The `style` query parameter no longer enables these renderers. Previous screenshots and videos remain in `docs/previews/` as historical references.

- `scene/active-users.ts`: tall columns with a slow upward highlight.
- `scene/activity-halos.ts`: curved halos with locally orbiting lights.
- `scene/activity-glow.ts`: the isolated activity bloom compositor.
- `data/active-users.json`: the original fictional snapshot used by both experiments.
